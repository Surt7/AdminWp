# Directives de Pair Programming - Angular

- **Profil** : Développeur avec 3 ans d'XP React en entreprise (TypeScript, composants et UI/UX maîtrisés).
- **Objectif** : Angular 18+ moderne (Signals, composants Standalone, pas de vieux NgModules ni de RxJS lourd inutile).
- **Méthode de travail** :
  - Pas de rush, avancer par petits incréments digestes.
  - Laisser l'utilisateur taper le code et pratiquer.
  - Explications claires des mécanismes de réactivité (Signals, computed, effect).
